## How this repo is organized

| Folder | What lives there |
|---|---|
| `frameworks/` | Maturity models, decision frameworks, checklists |
| `prds/` | Product requirement docs for real security problems |
| `teardowns/` | Product and market analyses |
| `threat-models/` | Threat models for AI agents, identity flows, and integrations |
| `metrics/` | KPI and OKR designs for security products and programs |
| `playbooks/` | Execution plans with timelines |
| `policies/` | Drop-in policy and standard templates |
| `essays/` | Longer points of view |
| `prototypes/` | Small scripts and demos |
| `linkedin/` | The post that accompanied each artifact, with results |
| `templates/` | The templates I use to write each artifact and post |
