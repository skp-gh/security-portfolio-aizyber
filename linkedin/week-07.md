## Share text

How many MCP servers are your AI agents connected to right now? Not approved. Running.

MCP made connecting agents to tools easy. That's exactly why it skipped the review we'd give any other privileged integration.

A developer adds a community server to her coding agent with three lines of config. A platform team puts one broad service token behind an internal server so every agent can use it. Both ship in an afternoon.

2025 already showed how this goes wrong: poisoned tool descriptions, a command injection in the client tooling, and a package that started copying emails after a quiet update.

This week I walked MCP through STRIDE to find where the trust boundaries really sit. The one most teams miss: tool descriptions are untrusted input.

Agentic Identity Notes, week 7. Do you know which of your MCP servers run on a shared service token?
