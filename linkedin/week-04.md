## Share text

Pick one AI agent. Revoke every credential it holds, everywhere. How long would that take you?

Revocation is the step everyone assumes is easy. Then a vendor emails on a Thursday afternoon asking customers to rotate credentials, and the team discovers grants under three employee accounts, a key copied into a CI variable, and a refresh token sitting on someone else's servers.

So this week I wrote a PRD for the agent credential lifecycle: issue, scope, rotate, revoke. The requirement I'd build first is the last one. One action that cuts an agent off across every system, with a measured time and proof it worked.

Inside the article: a scenario you'll probably recognize, the field most credential inventories are missing, and a drill you can run this week with a timer and a notepad.

Agentic Identity Notes, week 4. If you ran that drill tomorrow, which system would be the last to let go?
